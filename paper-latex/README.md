# Paper

LaTeX source of *Blockchain Data Availability: Benchmarking Throughput, Economics, Utilization, and Security of Six Production Protocols* (Elsevier `elsarticle`, 5p double-column).

## Build

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`elsarticle.cls` and `elsarticle-num.bst` are included, so a standard TeX Live or MacTeX installation is sufficient.

## Layout

| Path | Contents |
|---|---|
| `main.tex` | Front matter, abstract, section includes |
| `sections/` | One file per section |
| `tables/` | Results tables, generated by `protocol/shared/make_tables.py` (do not edit) |
| `figures/` | Figures, generated by the plotting scripts below |
| `references.bib` | Bibliography |

## Regenerating tables and figures

From the repository root:

```bash
python3 protocol/<Protocol>/data/transform.py          # Polkadot, Ethereum, Celestia, Espresso, Near, Avail
python3 protocol/shared/make_tables.py                 # writes paper-latex/tables/*.tex
FGCS_COMPACT=1 python3 protocol/<Protocol>/analysis/plot.py
FGCS_COMPACT=1 python3 protocol/Ethereum/analysis/plot_fgcs.py
FGCS_COMPACT=1 python3 protocol/shared/cross_protocol_fgcs.py
```

The figure files used by the paper are copied from `protocol/*/analysis/out/` and `protocol/shared/out_fgcs/`; file names are given in `sections/results.tex`. The Docker image runs the same steps: `docker run -v ./protocol:/app/protocol da-research all transform`, then `all plot`.
